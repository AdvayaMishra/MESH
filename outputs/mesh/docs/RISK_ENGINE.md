# Unified risk and retained-evidence contracts

Backend only. The new engine does not rewrite Incident.risk or pretend old incidents retained model versions.

POST /api/v1/vader/risk-policies requires organization.manage (owner, privileged MFA in production). Weights include exactly identity, behavior, network, api, privilege, data_access, cloud_posture and code_security; strict integers 0..100 summing to 100. Defaults: 15/15/10/10/15/15/10/10. Classification thresholds default to medium=25/high=50/critical=75 and must be strictly ordered inside 0..100. Every change creates an immutable numbered version; no update/delete endpoint. GET /risk-policies is owner/analyst scoped and paginated.

POST /api/v1/vader/risk-assessments requires security.read, a request_key, optional policy_id, window_hours 1..168 (default 24) and strict synthetic boolean (default false). Omitted policy selects the latest version on first admission. Replays retain that original policy/snapshot; changed arguments or another requester reusing the key return 409. Missing policy is 409; foreign IDs are 404. History/detail routes require security.read; history defaults to real assessments. Owner-only /risk-summary exposes scores/coverage, never raw evidence.

Algorithm mesh-risk-v1 normalizes telemetry to twice the maximum retained anomaly weight per event, capped at 100; each event belongs to one dimension. Statistical volume events map to behavior rather than being counted again in API/data access. Component scores take the maximum observed signal. Severity levels info/low/medium/high/critical map to 10/25/50/75/100. Cloud posture uses an available nonpartial assessment in the requested window; unresolved code findings remain exposure signals regardless of age. Absence of findings is unknown, not a verified clean scan. Synthetic mode excludes live code/cloud inputs. No source/secret values enter risk snapshots.

Known-dimension weights are renormalized for the provisional overall score; no known weighted inputs means null/unassessed. Coverage weight and missing-dimension lower/upper bounds are explicit. A complete weighted input vector is not proof of complete asset/connector coverage or detection sensitivity. Scores/classifications are policy signals, not probabilities, validated predictions or proof of attack. Nothing authorizes automatic enforcement. Network/behavior telemetry categories and configurable volume thresholds are supported; no real network connector is fabricated.

Snapshots retain policy/algorithm versions, component weights/scores, bounded source IDs, counts/truncation, window, synthetic provenance, explanation and uncertainty. History comparison/delta is available only for the same policy, window length and known-dimension set; otherwise delta is null. DB triggers reject snapshot/policy update/delete and composite FKs prevent cross-tenant references. Retirement preserves telemetry in assessment windows, including IDs omitted by response-size bounds. Telemetry input is capped at 10,000 events per assessment, selected before detector aggregation; excessive inventories fail closed.

GET /vader/incidents/{id}/risk-evidence is a separate versioned projection of retained legacy event weights. It reports missing evidence and unknown original model version; it never rewrites the stored score. GET /ai/risk-assessments/{id} supplies only authorized numeric aggregates to the configured provider; deterministic local templates are not model inference. All routes are specified in openapi.json.
